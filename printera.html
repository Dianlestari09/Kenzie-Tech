Masalah Umum

Keterbatasan Printer Kasir Cina

Banyak printer kasir Cina di pasaran tidak memiliki driver resmi untuk Android. Akibatnya, aplikasi bawaannya sangat terbatas dan Anda tidak bisa mencetak bebas dari aplikasi lain di HP Anda.

Solusi PrinterA

Driver Universal Android

PrinterA hadir untuk menggantikan fungsi driver sistem operasi Android. Dengan aplikasi kami, printer kasir Anda langsung dikenali sebagai printer sistem, memungkinkan pencetakan dari aplikasi APAPUN.

Dukungan Format File Lengkap

Cetak berbagai format dokumen, termasuk penerimaan share data dari aplikasi seperti WhatsApp.

Dokumen PDF

Cetak invoice, laporan, atau e-book langsung dengan layout yang rapi tanpa terpotong.

Image / Gambar

Mendukung pencetakan JPG, PNG. Bagikan gambar dari galeri atau WhatsApp dan langsung cetak.

Microsoft Word

Cetak file doc/docx dengan mudah. Cocok untuk dokumen teks dan surat jalan.

4 Langkah Mudah Pemakaian

1

Pilih File

Pilih menu "Cetak" atau "Share" dari aplikasi apa saja (WhatsApp, Galeri, File Manager) di HP Anda.

2

Sistem Android

Sistem Android akan menampilkan opsi menu Print / Cetak bawaan HP.

3

Pilih PrinterA

Pada daftar printer tujuan di bagian atas layar, pilih "PrinterA".

4

Cetak Dokumen

Pop-up Print Dialog terbuka, sesuaikan pengaturan jika perlu, lalu klik ikon cetak di bawah.

Integrasi Langsung dengan Aplikasi Lain

Selain terdaftar sebagai driver printer, aplikasi PrinterA juga terdaftar sebagai aplikasi yang bisa membuka langsung file PDF, Image, dan Ms. Word.

Jadi misalkan di WA, ketika ada file PDF yang diklik, maka PrinterA akan ditampilkan sebagai salah satu aplikasi yang bisa membuka file tersebut. Atau juga ketika dari aplikasi lain yang klik share file image, aplikasi PrinterA juga akan tampil sebagai salah satu pilihan.

Proses Cetak & Pengecekan Status

Sederhananya setelah langkah ke empat di atas atau terima share data dari aplikasi lain maka aplikasi PrinterA akan terbuka dengan menampilkan print dialog seperti ini dan tinggal klik icon Printer di bagian bawah, maka yang tampil di layar aplikasi akan dicetak di printer.

Tentunya ada beberapa fitur tambahan di luar print sederhana seperti ini.

Panduan

Cara cek status: Jika ada kendala saat mencetak, Anda dapat mengecek status printer di halaman ini. Jika masalah berlanjut, hubungi admin untuk bantuan lebih lanjut.
