Perbedaan Utama

Lebih Banyak Format Printer

Kecepatan dan skala bisnis antara PrinterA dan PrinterL pada dasarnya sama saja. Perbedaan utamanya terletak pada dukungan format data printer. Aplikasi PrinterA hanya mendukung format ESC/POS. Jika printer Anda menggunakan format lain (contohnya layaknya perbedaan format HP dan Canon yang pastinya berbeda), maka Anda bisa menggunakan aplikasi PrinterL.

Setting Printer

Pengaturan Spesifik

Perbedaan antara PrinterA dengan PrinterL hanyalah pada bagian Setting Printer. PrinterA tidak banyak yang perlu di-setting karena hanya ada satu pilihan format. Sedangkan pada PrinterL, karena ditujukan untuk berbagai tipe, maka terdapat beberapa opsi tambahan yang perlu diisi seperti command type dan ukuran label.

Opsi Lanjutan

Tampilan Setting PrinterL

Berbeda dengan PrinterA, menu Setting pada PrinterL memberikan Anda kontrol penuh atas format dan ukuran cetakan sesuai dengan spesifikasi printer Anda.

  • Pilihan Format: Dropdown untuk memilih command type (ESC, CPCL, TSPL V1, TSPL V2).
  • Dimensi Kertas: Kolom khusus untuk memasukkan Tinggi Label (misal: 100mm) dan Lebar Kertas (misal: 80mm).

Fitur & Dukungan PrinterL

Multi Command Type

Menyediakan beberapa pilihan format data / command type seperti ESC, CPCL, TSPL V1, dan TSPL V2.

Pengaturan Label

Mendukung pengaturan spesifik untuk pencetakan label, termasuk penyesuaian Tinggi Label (misal: 100mm) dan Lebar Kertas (misal: 80mm).

Self Test Print

Sangat dianjurkan untuk melakukan Self Test Print pada printer Anda untuk mengetahui Mac Address dan Format Printer yang tepat.

Pencarian Perangkat

Mendeteksi semua perangkat Bluetooth yang menyala di sekitar. Pastikan memilih Mac Address yang sesuai berdasarkan hasil Self Test Print.

Performa Setara

Memiliki kualitas performa, kecepatan cetak, dan keandalan yang sama tingginya dengan aplikasi PrinterA.

Kemudahan Akses

Sama seperti PrinterA, terintegrasi baik dengan sistem Android untuk mencetak langsung dari berbagai aplikasi di HP Anda.
